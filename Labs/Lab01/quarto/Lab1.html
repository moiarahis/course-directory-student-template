1.1.1 Цель работы

Изучить принципы работы шифров простой замены и реализовать программные алгоритмы шифра Цезаря с произвольным ключом и шифра Атбаш.

1.2 1. Шифр цезаря.

При шифровании каждая буква исходного текста заменяется другой буквой того же алфавита. Положение новой буквы определяется с помощью ключа k. Для символа с номером i новая позиция определяется следующим образом:

\[ (i + k) \bmod m, \]

где:

-‘i’ - позиция символа в алфавите; -‘k’ - ключ шифрования; -‘m’ - количество символов в алфавите

Использование оперции остатка от деления позволяет выполнять циклический сдвиг символов алфавита.

latin_alphabet = "abcdefghijklmnopqrstuvwxyz"
russian_alphabet = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"

2 2.8 описание алгоритма функции

### 1.2 Реализация шифра цезаря
Для шифрования текста программа последовательно обрабатывает каждый символ текста. Если символ является буквой рускогшо алфавита, определяется его текущая позиция. Затем позиция изменяется на величину ключа. После этого определяется новый символ, который добавляется в результат шифрования.
text_latin = "venividivici"             #входной текст
shift = 3                               #длина  сдвига
encrypted_latin = ""                    #переменная для зашифрованного текста

#алгоритм шифрования
for char in text_latin:
    if char in latin_alphabet:
        idx = latin_alphabet.index(char)
        new_idx = (idx + shift) % len(latin_alphabet)
        encrypted_latin += latin_alphabet[new_idx]
    else:
        encrypted_latin += char

2.0.1 1.3 Проверка работы программы

Для проверки работы алгоритма задаётся исходный текст и ключ шифрования. После шифрования полученый текст расшифровывается с использованием отрицательного значения ключа. Если алгоритм работает правильно, результат дешифрования должен совпасть с исходным текстом.

descrypted_latin = ""                   #переменная для расшифрованного текста
for char in encrypted_latin:            #алгоритм дешифровки текста
    if char in latin_alphabet:
        idx = latin_alphabet.index(char)
        new_idx = (idx - shift) % len(latin_alphabet)
        descrypted_latin += latin_alphabet[new_idx]
    else:
        descrypted_latin += char

#вывод результатов алгоритма
print (f"Исходный:      {text_latin}")          #вывод исходного текста
print (f"Зашифрованный:      {encrypted_latin}")          #вывод зашифрованного текста
print (f"Расшифровка:      {descrypted_latin}")          #вывод расшифрованного текста

2.1 2. Шифр Атбаш.

Шифр Атбаш основан на зеркальном отображении символов алфавита. Первой букве алфавита соответствует последняя буква и т.д. Для получения нового символа определяется позиция буквы с противоположного конца алфавита.

2.1.1 2.1 Реализация шифра Атбаш

Программа последовательно обрабатывает каждый символ исходного текста. Если символ принадлежит русскому алфавиту, определяется его позиция в алфавите. После этого вычисляется зеркальнаая позиция:

\[ m - 1 - i, \]

где: m - количество символов в алфавите; i - позиция исходного символа; Полученый символ добавляется к результату.

latin_alphabet = "abcdefghijklmnopqrstuvwxyz"
russian_alphabet = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"

text_latin = "venividivici"             #входной текст
encrypted_latin = ""                    #переменная для зашифрованного текста

#отзеркеаливание букв алфавита
mapping_latin = {latin_alphabet[i]: latin_alphabet[len(latin_alphabet) - 1 - i] for i in range(len(latin_alphabet))}

for char in text_latin:
    if char in mapping_latin:
        encrypted_latin += mapping_latin[char]
    else:
        encrypted_latin += char

2.1.2 2.2 Проверка работы программы

Особенностью шифра Атбаш является то, что одна и та же операция используется для шифрования и дешифрования. Поэтому одна и та же функция применяется к исходному тексту для получения шифрованного текста, а затем повторно рпименяется для получения исходного текста.

descripted_latin = ""                       #переменная для расшифрованного текста
for char in encrypted_latin:                #алгоритм дешифровки текста
    if char in mapping_latin:
        descripted_latin += mapping_latin[char]
    else:
        descripted_latin += char

#вывод результатов работы алгоритма
print ("Атбаш")
print (f"Исходный:          {text_latin}")
print (f"Зашифрованный:     {encrypted_latin}")
print (f"Расшифровка:       {descripted_latin}")
